# Что здесь настоящее и откуда взялось

Заготовок в наполнении больше нет. Этот файл теперь отвечает на другой
вопрос: **откуда взялся каждый кусок содержимого** — и что стоит перечитать
человеку, прежде чем показывать ученикам.

Проверить текущее состояние, ничего не записывая:

```bash
cd backend && npm run content -- --check
```

---

## Источники

| Файл | Откуда содержимое |
|---|---|
| `topics/*.json` (10 предметов) | список тем учебников 5–11 классов из `docs/raw material/все темы список.txt` |
| `topics/logic.json` | типология раздела «Количественные характеристики» из `docs/raw material/кол. характеристики.txt` |
| `topics/reading_literacy.json`, `topics/math_literacy.json` | разделы ЕНТ; составлены по описанию разделов |
| `lessons/*.json`, 5–6 классы | тексты параграфов учебников из `docs/raw material/материал (по предметам)/` |
| `lessons/*.json`, 7–10 классы | тексты параграфов учебников оттуда же |
| `lessons/*.json`, 11 класс и пробелы (биология 7, казахский 7, английский 9, информатика 8) | написаны вручную по темам списка |
| `questions/diagnostic.json` | написаны вручную по темам |
| `questions/mock-ent.json`, `questions/mock-nis.json` | написаны вручную по темам и описанию разделов |
| `exams.json` | ЕНТ и НИШ — по официальным описаниям экзаменов |
| `subjects.json`, `goals.json` | составлены вручную |

Механика воспроизводится двумя командами, и **ни одна из них не обращается
к платным сервисам** (`docs/13-work-rules.md`, §1):

```bash
npx tsx scripts/import-raw.ts                 # темы и уроки из сырого материала
npx tsx scripts/add-lessons.ts <файл.json>    # добавить написанные вручную уроки
```

`import-raw.ts` детерминированный: перечитывает сырой материал и перезаписывает
уроки, вычитанные из учебников. Написанные руками уроки он сохраняет —
их темы в сыром материале отсутствуют.

Формат файла для `add-lessons.ts`:

```json
[{ "topic_code": "math.g11.…", "summary": "…", "body_md": "## …" }]
```

Остальное — код урока, план, `ai_text`, время чтения — выводится автоматически.

## Что стоит перечитать человеку

1. **Тексты, снятые со сканов.** Распознавание местами испорчено: встречаются
   «Можот ли уравнонио» вместо «Может ли уравнение». Файлы в
   `docs/raw material/материал (по предметам)/` **можно и нужно править** —
   но только грамматику и явно битые места, не содержание.
2. **Эталонные ответы в вопросах.** Неверный ключ хуже отсутствия вопроса:
   ученик получит «неверно» за верный ответ, а мастерство просядет.
3. **Раздел «Количественные характеристики»** — задания сравнивают две
   величины, и ошибка в вычислении не видна на глаз.

Правки вносятся прямо в JSON и загружаются `npm run content`.

## Что известно неточным

* **Пары профильных предметов ЕНТ.** Официальных комбинаций двенадцать;
  в `exams.json` перечислены четыре — те, что состоят из поддерживаемых
  приложением предметов. Остальные (география, всемирная история, основы
  права, литература, иностранный язык) появятся вместе со своим наполнением.
* **Темы даны выборкой.** По пять тем на предмет и класс — ровно так, как
  в `все темы список.txt`. Это не полная программа: логарифмов, векторов
  и стереометрии в математике, например, нет вовсе. Так задумано —
  объём наполнения зафиксирован (`docs/13-work-rules.md`, §4).

## Правила правки

* **Не менять `code` у уже загруженного** — записи привязаны к нему, и смена
  кода создаст вторую запись вместо правки первой.
* Исчезнувшие из файлов темы, уроки и вопросы загрузчик снимает с публикации
  сам. В новые тесты они не попадут, а пройденные попытки останутся читаемыми.
* `ai_text` у материала — то, что видит модель. Пусто — материал в контекст
  не попадёт вовсе; так и задумано для сканов страниц и фотографий.

cd backend
npm run content -- --check    # проверить, ничего не записывая
