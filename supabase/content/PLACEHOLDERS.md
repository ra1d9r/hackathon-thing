# Что здесь пока не настоящее

Одиннадцать файлов из этого каталога содержат **заготовки**: система на них
работает целиком — тест собирается, проходится, оценивается, статистика
пересчитывается, — но учебной ценности в самом содержимом нет.

**Диагностический тест заготовкой уже не является.** В нём 43 вопроса
по пяти предметам с настоящими темами: математика, физика, история
Казахстана, грамотность чтения, математическая грамотность. Шесть из них —
со свободным ответом, с критериями оценивания; именно на них проверялась
работа модели. Заменять их не нужно, но можно: правила те же.

Остальное — материалы и пробники — намеренно оставлено заготовками.

**Как узнать текущий список, не читая этот файл:**

```bash
cd backend && npm run content -- --check
```

Команда ничего не записывает и печатает каждую заготовку с пояснением,
что именно в ней временное.

---

## Как понять, что файл — заготовка

Внутри стоят две пометки, и они всегда идут вместе (за этим следит тест
`content.test.ts`):

```json
{
  "_ЗАГОТОВКА": "чем именно плохо текущее содержимое и что нужно сделать",
  "placeholder": true,
  ...
}
```

Заменили содержимое настоящим — поставьте `"placeholder": false` и удалите
строку `_ЗАГОТОВКА`. Файл пропадёт из отчёта загрузки; так видно, что осталось.

## Список

Порядок — по влиянию на работу системы. Сверху то, без чего остальное
теряет смысл.

### 1. `lessons.json` — 3 урока

Дорожная карта строится только по темам, обеспеченным материалом. С тремя
уроками она получится длиной в три шага.

Что заменить: массив `lessons`. Нужен минимум один урок на тему, которую
предполагается изучать.

Про два представления материала — для ученика и для модели — см. §6.6
в `docs/04-domain-logic.md`: ученику показывается `body_md` (можно сканы
и фотографии), модели уходит только плоский `ai_text`. Материал без `ai_text`
в контекст модели не попадает вовсе.

### 2. `questions/mock-ent.json` — 20 вопросов

Краткая форма вместо полного пробника на 140 баллов. Приведение к шкале
чертежа работает и на 20 вопросах, но замер получается грубым: одна ошибка
стоит слишком дорого.

### 3. `questions/mock-nis.json` — 4 вопроса

Демонстрационный набор. Как и ЕНТ, этот тест составляет человек: модель его
не генерирует и не редактирует, только анализирует результаты.

Отдельно: в `exams.json` распределение баллов по секциям НИШ проставлено
по нашему усмотрению и помечено внутри файла — стоит сверить с официальными
требованиями.

### 4. Темы восьми предметов — по 6 тем в каждом

```
topics/biology.json          topics/informatics.json      topics/natural_science.json
topics/chemistry.json        topics/kazakh_language.json  topics/russian_language.json
topics/english_language.json topics/logic.json
```

Названия сгенерированы формально. Предметы можно выбрать в онбординге, но
обучение по ним будет бессодержательным.

Что заменить: `code`, `title_ru`, диапазон классов, `exam_weight` и порядок.

**Темы этих пяти предметов — настоящие**, их трогать не нужно:
`math`, `physics`, `kz_history`, `reading_literacy`, `math_literacy`
(96 тем всего).

## После правки

```bash
cd backend
npm run content -- --check    # проверить, ничего не записывая
npm run content               # записать в базу
```

Проверка делает настоящую загрузку в транзакции и откатывает её, поэтому
ловит и опечатки в структуре, и ссылки на несуществующие темы.

Одно правило, которое легко нарушить: **не меняйте `code` у уже загруженного**.
Записи привязаны к нему, и смена создаст вторую запись вместо правки первой.
Переименование — это удаление старой записи и добавление новой.

Вопрос, исчезнувший из файла, загрузчик снимает с публикации сам: в новые
тесты он не попадёт, а уже пройденные попытки с ним останутся читаемыми.
Сколько вопросов снято, печатается после загрузки.
