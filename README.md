# Tlek (Тілек)

Мобильное приложение с ИИ-репетитором для учеников 7–12 классов.

## Что это

Это мобильное приложение с ИИ-репетитором, который помогает при подготовке к всевозможным экзаменам, и обычным предметам. Для подготовки используются реальные учебники, но фишка проекта - ИИ сам собирает задачи и персонализирует подход по ответам студента (ежедневные задачи, пробники и прочие задания), то есть ИИ сам анализирует сильные и слабые стороны студента и подбирает нужные задания, темы и т.п. Также присутствует подготовка к поступлению в НИШ. 


При первом входе ученик проходит опросник: для чего готовится (ЕНТ, подтягивание знаний по выбранным предметам, олимпиада, экзамен в НИШ), какие профильные предметы выбирает и в каком он классе. Дальше — заранее собранный человеком диагностический тест по выбранным предметам (вопросы без вариантов ответа, ученик пишет ответ сам), после которого ИИ разбирает весь тест и определяет сильные и слабые стороны ученика.

Дальше ученику доступны:

- **Панель** - сегодняшний фокус по темам/урокам, ориентировочный балл на желаемом экзамене, аналитика (сравнение текущего результата с предыдущими, число отвеченных вопросов, часы в обучении, график прогрессии результата, текущие слабые темы), дневные задачи со streak и прогрессом вида «2/3», с прямым переходом к решению по кнопке, predicted score на желаемом экзамене. Если экзамен не выбран, а цель — просто подтянуть знания, вместо баллов выставляется оценка из 10 с ориентиром на школьную 5-балльную (9–10 → 5, 7–8 → 4, 5–6 → 3, 3–4 → 2, 1–2 → 1)
- **Обучение** - отдельная от дневных задач вкладка: тема для изучения, затем задание на повторение и закрепление, а ещё материалы от учителя. Материал можно читать офлайн, но выполнять задания — только при подключении к сети.
- **Прогресс** - roadmap с пройденными уроками (процент прохождения каждого) и predicted score на желаемом экзамене; если экзамен не выбран, а цель — просто подтянуть знания, вместо баллов выставляется оценка из 10 с маппингом на школьную 5-балльную (9–10 → 5, 7–8 → 4, 5–6 → 3, 3–4 → 2, 1–2 → 1). При выборе урока или задания заранее показывается его состав — например «1. Интро, 2. Тема, 3. Задание».
- **Чат** — отдельный от канала, по которому учитель рассылает уроки.
- **Профиль** — аватар (стандартные форматы изображений, изменяемый), имя, класс, уникальный неизменяемый ID пользователя, который выдаётся при регистрации.
- **ИИ-ассистент** - персонально объясняет темы, помогает с заданиями, говорит, какие темы отстают и какой сейчас план обучения, отвечает на другие вопросы по учёбе. Ограничен инструкциями от нерелевантных и запрещённых тем: NSFW, психологические темы, NSFL, политика/идеология вне школьной программы истории, темы, слишком сложные для класса ученика.


Также есть заранее подготовленные пробники ЕНТ. ИИ не создаёт их, а только анализирует ответы ученика, сравнивает с прошлыми попытками и поправляет по ним статистику и план обучения.

## Учительская часть

- **Классы** - вкладка для управления классами, то есть создание классов, добавление учеников по публичному ID и исключение учеников из классов.
- **Материалы** - вкладка для создания и отправления ученикам уроков и материалов. Включает в себя загрузку видео, PDF, PPTX, DOCX, TXT, ссылки или текст во встроенном редакторе с форматированием, рассылки по классам, чат с закреплением сообщений, личный кабинет. Загруженные материалы удаляются автоматически через 30 дней.
- **Чат** - чат с учениками разных классов.

Учителем нельзя зарегистрироваться самостоятельно: подаётся заявка с почтой организации, специальный whitelist домены одобряются автоматически.

## Роль ИИ

ИИ персонализирует все задачи и тесты (кроме первичного диагностического и пробников ЕНТ) под ответы, предмет и материал конкретного ученика. Он анализирует ответы после тестов и заданий, поправляет проценты понимания тем и предметов, выставляет оценки и баллы. По этим же данным ИИ собирает roadmap ученика (подбор материала и генерация заданий) и предположительный результат (predicted score / оценка из 10).

При этом ИИ не имеет прямого доступа на запись в базу — он возвращает структурированные решения по статистике и roadmap, а их проверку (диапазоны значений, целостность, отсутствие дублей, сохранение истории) и финальное применение выполняет backend. Долгие ИИ-операции идут через очередь отложенных запросов, чтобы система не падала от перегрузки внешнего ИИ API.

Логика статистики устроена так, что по мере роста процента понимания темы её приоритет в проблемных снижается, а при достижении 100% тема убирается из проблемных вовсе.

## Роли и доступ

Ученик и учитель — разделены по роли. У каждого пользователя есть уникальный неизменяемый ID, который присваивается при регистрации. Аутентификация сохраняется между запусками приложения, доступ к защищённым экранам без неё невозможен.

## Технологии
Клиент: React Native, Expo Router, TypeScript strict, Zustand
Backend: Fastify 5, Zod, postgres.js, TypeScript strict
Данные: Supabase — Postgres, Auth, Storage
Хостинг: Render, в котором статический сайт + web-сервис
Online-first архитектура с ограниченными офлайн-элементами (чтение материалов), не завязанными на основной функционал.
