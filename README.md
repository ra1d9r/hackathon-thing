# Tlek (Тілек)

Мобильное приложение с AI-репетитором для учеников 7–12 классов.

## Что это

Это мобильное приложение с AI-репетитором, который помогает при подготовке к всевозможным экзаменам, и обычным предметам. Для подготовки используются реальные учебники, но фишка проекта - ИИ сам собирает задачи и персонализирует подход по ответам студента (ежедневные задачи, пробники и прочие задания), то есть ИИ сам анализирует сильные и слабые стороны студента и подбирает нужные задания, темы и т.п. Также присутствует подготовка к поступлению в НИШ. 



При первом входе ученик проходит опросник: для чего готовится (ЕНТ, подтягивание знаний по выбранным предметам, олимпиада, экзамен в НИШ), какие профильные предметы выбирает и в каком он классе. Дальше — заранее собранный человеком диагностический тест по выбранным предметам (вопросы без вариантов ответа, ученик пишет ответ сам), после которого AI разбирает весь тест и определяет сильные и слабые стороны ученика.

Дальше ученику доступны:

- **Student Dashboard** - сегодняшний фокус по темам/урокам, ориентировочный
  балл на желаемом экзамене, аналитика (сравнение текущего результата с
  предыдущими, число отвеченных вопросов, часы в обучении, график прогрессии
  результата, текущие слабые темы), дневные задачи со streak и прогрессом
  вида «2/3», с прямым переходом к решению по кнопке.
- **Материалы и проверка знаний** - отдельная от дневных задач вкладка: тема
  для изучения, затем задание на повторение и закрепление. Материал можно
  читать офлайн, но выполнять задания — только при подключении к сети.
- **Прогресс ученика** - roadmap с пройденными уроками (процент прохождения
  каждого) и predicted score на желаемом экзамене; если экзамен не выбран, а
  цель — просто подтянуть знания, вместо баллов выставляется оценка из 10
  с маппингом на школьную 5-балльную (9–10 → 5, 7–8 → 4, 5–6 → 3, 3–4 → 2,
  1–2 → 1). При выборе урока или задания заранее показывается его состав —
  например «1. Интро, 2. Тема, 3. Задание».
- **Профиль** — аватар (стандартные форматы изображений, изменяемый), имя,
  класс, уникальный неизменяемый ID пользователя, который выдаётся при
  регистрации.
- **AI-ассистент** - персонально объясняет темы, помогает с заданиями,
  говорит, какие темы отстают и какой сейчас план обучения, отвечает на
  другие вопросы по учёбе. Ограничен инструкциями от нерелевантных и
  запрещённых тем: NSFW, психологические темы, NSFL, политика/идеология вне
  школьной программы истории, темы, слишком сложные для класса ученика.
- **Чат класса с учителем** — отдельный от канала, по которому учитель
  рассылает уроки.

Также есть заранее подготовленные пробники ЕНТ
AI не создаёт их, а только анализирует ответы ученика, сравнивает с прошлыми попытками и поправляет по ним статистику и план обучения.

## Учительская часть

**Teacher Dashboard** позволяет добавлять учеников в свой класс по их ID и
рассылать уроки: файлами (видео, PDF, PPTX, DOCX, TXT), ссылками или прямо
во встроенном редакторе с базовым форматированием (заголовки разных
уровней, курсив, жирный, подчёркнутый и зачёркнутый текст, цитаты, списки).

## Роль AI

AI персонализирует все задачи и тесты (кроме первичного диагностического и
пробников ЕНТ) под ответы, предмет и материал конкретного ученика. Он
анализирует ответы после тестов и заданий, поправляет проценты понимания
тем и предметов, выставляет оценки и баллы. По этим же данным AI собирает
roadmap ученика (подбор материала и генерация заданий) и предположительный
результат (predicted score / оценка из 10).

При этом AI не имеет прямого доступа на запись в базу — он возвращает
структурированные решения по статистике и roadmap, а их проверку (диапазоны
значений, целостность, отсутствие дублей, сохранение истории) и финальное
применение выполняет backend. Долгие AI-операции идут через очередь
отложенных запросов, чтобы система не падала от перегрузки внешнего AI API.

Логика статистики устроена так, что по мере роста процента понимания темы
её приоритет в проблемных снижается, а при достижении 100% тема убирается
из проблемных вовсе.

## Роли и доступ

Ученик и учитель — разделены по роли. У каждого пользователя есть
уникальный неизменяемый ID, который присваивается при регистрации.
Аутентификация сохраняется между запусками приложения, доступ к защищённым
экранам без неё невозможен.

## Технологии

React Native + TypeScript на клиенте, Supabase (Postgres + Auth + Storage) и
REST API на бэкенде, online-first архитектура с ограниченными офлайн-
элементами (чтение материалов), не завязанными на основной функционал.
